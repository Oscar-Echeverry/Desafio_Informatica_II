# Sweet Crush

## Desafío #1 – Informática II
### Universidad de Antioquia – UdeA

Proyecto desarrollado en **C++** como parte del curso de **Informática II**.

El objetivo principal fue implementar una versión de **Sweet Crush**, trabajando conceptos como operaciones con bits, memoria dinámica, punteros, manejo de arreglos, combinaciones, gravedad y modificación dinámica del tablero.
